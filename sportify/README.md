# CSV → Spotify Playlist

این اسکریپت فایل `tracklist.csv` (همون لیست ۳۰۴ آهنگی که از ویدیو استخراج شد) رو می‌خونه،
هرکدوم رو تو اسپاتیفای جستجو می‌کنه، و پیداشده‌ها رو به یک پلی‌لیست اضافه می‌کنه.
در صورت نیاز تمام این لیست رو شخصی سازی کنید
## مرحله ۱: نصب پیش‌نیاز

```bash
pip install -r requirements.txt
```

## مرحله ۲: ساخت اپلیکیشن اسپاتیفای

1. به [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) برید
2. **Create app** بزنید
3. در **Redirect URI** بنویسید: `http://127.0.0.1:8080`
4. `Client ID` و `Client Secret` رو کپی کنید
5. حتما داخل تنظیمات ربات یوزرهایی که میتونن دسترسی داشته باشن رو ادد کنید که به مشکل نخورید
## مرحله ۳: پر کردن تنظیمات

فایل `csv_to_spotify.py` رو باز کنید و این مقادیر رو پر کنید:

```python
SPOTIFY_CLIENT_ID = "..."
SPOTIFY_CLIENT_SECRET = "..."
```

نیازی به ساختن پلی‌لیست یا گرفتن آیدی نیست — اسکریپت خودش یه پلی‌لیست جدید به اسم
`PLAYLIST_NAME` می‌سازه. اگه می‌خواید به‌جای پلی‌لیست، آهنگ‌ها مستقیم به **Liked Songs**
اضافه بشن، `ADD_TO_LIKED_SONGS = True` کنید. اگه پلی‌لیست از قبل ساخته‌شده‌ای دارید،
آیدیش رو تو `SPOTIFY_PLAYLIST_ID` بذارید (Share → Copy link؛ بخش بعد از `/playlist/`).

مطمئن بشید فایل `tracklist.csv` تو همون پوشه‌ی اسکریپته (یا مسیرش رو تو `INPUT_CSV` عوض کنید).

## مرحله ۴: اجرا

```bash
python csv_to_spotify.py
```

اسکریپت با یوزرنیم/پسورد کار نمی‌کنه — بار اول یک صفحه مرورگر باز میشه که توش با
همون اکانت اسپاتیفای خودتون لاگین می‌کنید و اجازه‌ی دسترسی رو تایید می‌کنید (استاندارد OAuth
اسپاتیفای؛ هیچ پسوردی به اسکریپت داده نمیشه).

## خروجی‌ها

بعد از اجرا، سه چیز دارید:

1. **پلی‌لیست ساخته‌شده (یا Liked Songs)** تو اسپاتیفای با تمام آهنگ‌های پیداشده
2. **`not_found_tracks.csv`** — لیست آهنگ‌هایی که تو اسپاتیفای پیدا نشدن (خودتون دستی جستجو کنید یا بدونید موجود نیست)
3. **`matched_tracks.csv`** — دقیقاً نشون میده هر ردیف ورودی به کدوم ترک اسپاتیفای match شده؛
   چون بعضی وقتا match ممکنه دقیق نباشه (مثلاً یه کاور یا اجرای زنده به‌جای نسخه‌ی اصلی)،
   بهتره یه نگاه بهش بندازید.

## نکته

چون لیست ۳۰۰+ آهنگه، اجرا ممکنه چند دقیقه طول بکشه (به خاطر rate limit اسپاتیفای).
اگه اسکریپت وسط کار خطای rate limit داد، چند دقیقه صبر کنید و دوباره اجرا کنید — یا
`REQUEST_DELAY` رو تو فایل بیشتر کنید.
